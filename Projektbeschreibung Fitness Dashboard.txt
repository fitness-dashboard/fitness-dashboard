PROJEKTBESCHREIBUNG FITNESS DASHBOARD

# Ziel

Ziel des Projekts ist die tägliche Auswertung von:

* Körpergewicht
* Körperfett
* Muskelmasse
* Kalorienaufnahme
* Trainingskalorien
* Grundumsatz

Die Ergebnisse werden automatisch:

1. in Excel ausgewertet
2. als Diagramme dargestellt
3. nach GitHub hochgeladen
4. auf Streamlit veröffentlicht

# Technik

Programmiersprache:

* Python

Bibliotheken:

* pandas
* numpy
* xlwings
* plotly
* streamlit

Veröffentlichung:

* GitHub
* Streamlit Cloud

# Projektstruktur

## fitness_report.py

Hauptprogramm.

Aufgaben:

* Daten laden
* Berechnungen durchführen
* CSV für Dashboard exportieren
* Excel aktualisieren
* Diagramme erzeugen
* GitHub automatisch aktualisieren

## load_data.py

Import aller Rohdaten.

Datenquellen:

* MyFitnessPal Messwerte
* MyFitnessPal Nährwerte
* MyFitnessPal Trainingsdaten
* Tanita Waage

Besonderheiten:

* Tanita Altdaten werden aus
  D:\Documents\Gesundheit Kai\Diät\Altdaten Tanita Neu fertig.csv
  geladen.
* Aktuelle Tanita-Daten werden automatisch aus Downloads geladen.
* Beide Dateien werden zusammengeführt.
* Zeitraum beginnt am 14.06.2025.

## calculations.py

Alle Kennzahlen und Berechnungen.

Berechnet:

* Gewichtsdurchschnitt 7 Tage
* Körperfettanteil 7 Tage
* Muskelmasse 7 Tage
* Kalorien aus Essen Summe 30 Tage
* Kalorien aus Essen Summe 60 Tage
* Kalorien aus Training Summe 30 Tage
* Kalorien aus Training Summe 60 Tage
* Grundumsatz errechnet 30 Tage
* Grundumsatz errechnet 60 Tage
* Grundumsatz Mifflin-St.-Jeor

## excel_export.py

Exportiert den kompletten DataFrame nach Excel.

## charts.py

Erzeugt alle Excel-Diagramme.

## app.py

Streamlit Dashboard.

Liest:
fitness_dashboard_data.csv

und erzeugt die Online-Diagramme.

# Wichtige Berechnungen

## Gewichtsprognose

Es werden zwei Zielkurven berechnet:

* 300 kcal Defizit pro Tag
* 500 kcal Defizit pro Tag

Startpunkt:
14.06.2025

Die Kurven starten beim tatsächlichen Gewicht am 14.06.2025.

## Grundumsatz

Variante 1:

Variante 2:
