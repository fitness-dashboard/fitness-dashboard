PROJEKTBESCHREIBUNG FITNESS DASHBOARD

# Ziel

Ziel des Projekts ist die tägliche Auswertung von:

* Körpergewicht
* Körperfett
* Muskelmasse
* Kalorienaufnahme
* Trainingskalorien
* Grundumsatz
* Krafttraining (GymRun)

Die Ergebnisse werden automatisch:

1. in Excel ausgewertet
2. als Diagramme dargestellt
3. nach GitHub hochgeladen
4. auf Streamlit veröffentlicht

# Technik

Programmiersprache:

* Python

Bibliotheken:

* pandas
* numpy
* xlwings

Veröffentlichung:

* GitHub

# Projektstruktur

## fitness_report.py

Hauptprogramm.

Aufgaben:

* Daten laden
* Berechnungen durchführen
* CSV für Dashboard exportieren
* Excel aktualisieren
* Standarddiagramme erzeugen
* GymRun-Auswertungen erzeugen
* GitHub automatisch aktualisieren

## load_data.py

Import aller Ernährungs- und Körperdaten.

Datenquellen:

* MyFitnessPal Messwerte
* MyFitnessPal Nährwerte
* MyFitnessPal Trainingsdaten
* Tanita Waage

## load_gymrun.py

Import der GymRun Trainingsdaten.

Aufgaben:

* GymRun CSV automatisch aus Downloads laden
* Trainingsdaten bereinigen
* Datumsfelder konvertieren
* DataFrame für weitere Auswertungen bereitstellen

## calculations.py

Alle Kennzahlen und Berechnungen.

Berechnet:

* Gewichtsdurchschnitt 7 Tage
* Körperfettanteil 7 Tage
* Muskelmasse 7 Tage
* Kalorien aus Essen Summe 30 Tage
* Kalorien aus Essen Summe 60 Tage
* Kalorien aus Training Summe 30 Tage
* Kalorien aus Training Summe 60 Tage
* Grundumsatz errechnet 30 Tage
* Grundumsatz errechnet 60 Tage
* Grundumsatz Mifflin-St.-Jeor

## gymrun_calculations.py

Berechnet Trainingskennzahlen aus GymRun.

Berechnet:

* Tages-MaxRM pro Übung
* Trainingsvolumen pro Übung und Trainingstag

## gymrun_helpers.py

Hilfsfunktionen für GymRun.

Aufgaben:

* Extraktion einzelner Übungen
* Aufbereitung für Diagramme
* Filterung nach Startdatum

## gymrun_charts.py

Erzeugt Datenstrukturen und Excel-Diagramme für GymRun.

Funktionen:

* MaxRM Diagramme
* Volumen Diagramme
* Diagrammdaten aufbereiten
* Excel-Diagramme erzeugen

## gymrun_config.py

Zentrale Konfiguration aller GymRun Übungen.

Enthält:

* Startdatum pro Übung
* RM-Minimum
* RM-Maximum
* Volumen-Minimum
* Volumen-Maximum

## excel_export.py

Exportiert den kompletten DataFrame nach Excel.

## charts.py

Erzeugt alle Excel-Diagramme des Fitness-Dashboards.

## app.py

Streamlit Dashboard.

Liest:

fitness_dashboard_data.csv

und erzeugt die Online-Diagramme.

# Wichtige Berechnungen

## Gewichtsprognose

Es werden zwei Zielkurven berechnet:

* 300 kcal Defizit pro Tag
* 500 kcal Defizit pro Tag

Startpunkt:

14.06.2025

Die Kurven starten beim tatsächlichen Gewicht am 14.06.2025.

## Grundumsatz

Variante 1:

BMR (kcal) Tanita

Variante 2:

Grundumsatz errechnet 30 Tage

Variante 3:

Grundumsatz errechnet 60 Tage

Variante 4:

Mifflin-St.-Jeor x 1,12

# GymRun Auswertung

Aktuell werden folgende Übungen ausgewertet:

* Flachbankdrücken Langhantel
* Brustdrücken sitzend Gym90 ein Arm
* Latziehen am Turm 1 Arm
* Kreuzheben Langhantel
* Beinpresse am Gerät 1 Bein
* Wadenheben sitzend 1 Bein
* Schulterdrücken KH 1 Bein
* Bizeps Panatta
* Trizepsdrücken am Gerät 1 Arm
* Hammer Bankdrücken am Gerät 1 Arm

Für jede Übung werden berechnet:

## MaxRM

Höchstes geschätztes One-Rep-Maximum pro Trainingstag.

## Trainingsvolumen

Gesamtvolumen pro Trainingstag:

Gewicht × Wiederholungen × Sätze

# Automatisierung

Nach jedem Lauf:

1. CSV-Datei wird aktualisiert
2. Excel-Datei wird aktualisiert
3. GymRun-Diagramme werden neu erzeugt
4. Git Add
5. Git Commit
6. Git Push

Dadurch aktualisiert sich die Streamlit-Webseite automatisch.
